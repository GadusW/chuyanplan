# 0.18.0 专辑卡片与玻璃材质

本轮依据开发者手机截图、两张封面队列参考和 15.57 秒参考视频实现。参考媒体只在本机检查，不打包进应用。延续既有靛蓝、香槟月白与冰蓝配色、24 dp 边距和透明展开底栏；本页的封面交互替代此前点按封面显示歌词的旧约定。

## 真实封面

迷你播放器、乐库歌曲行和播放卡片均使用音频文件内嵌的专辑封面。没有内嵌图片时显示默认品牌图，不联网查找或猜配封面。解码在 IO 调度器执行，最多三路并发；24 MB LRU 缓存以 URI、修改时间和文件大小为键，包括无图结果，避免滚动反复解码。

## 顺序专辑卡片

「极简」更名为「播放模式」。当前曲目居中放大，右侧最多三张后续卡片用透视和比例表达顺序，左侧上一张只作位置上下文；不会把整库封面同时解码。

从卡片中部横拖，左移超过宽度 24% 后松手提交切歌：顶卡向左退出，下一张随手势前移、放大并转正。未到阈值及末曲拖动均回弹。一次完成的拖动只发送一次切歌。计数是「接下来 N 首」，不包括当前歌曲；切到下一首即减少。原播放队列保留，可以使用上一首按钮返回；不会删除本机文件、播放历史或队列中的歌曲。卡片切歌按屏幕上显示的队列顺序，独立于随机播放按钮；自动播放和常规控制仍遵循原循环／随机规则。

## 揭角歌词

右下角最多 64 dp 的区域接管向内拖动；紧凑卡片的触区限制为边长的 45%，避免遮住中部切歌区域。其余区域横拖用于切歌。卡片外框位置和角度固定。折线是原右下角与手指对应点之间的垂直平分线：正面按半平面裁切，折片顶点沿该线镜像，原角落位置与手指保持一致，露出的三角区域显示歌词背面。折片有浅色纸背、定向明暗和细折痕，短拖只露一角。

松手后在 300 ms 内反向重放记录的揭角路径回落，不触发切歌，也不永久切到歌词。歌词按钮及揭角区域的无障碍操作可打开完整歌词；明确的「返回封面」、导入和逐句跳转入口保留。系统关闭动画时遵循 Compose 动画缩放；直接跟手拖动继续响应。

## 玻璃表面

环境单独录入 GraphicsLayer，玻璃只读取该层，避免递归采样自己的文字与边缘。面板按其屏幕位置采样实际环境，做 1.055 倍透镜放大和 2 dp 位移，叠加低透明度亮面、方向性细边与内侧折射亮带。背景仍是柔焦的明暗环境，正文和控制保持锐利。首页、搜索、迷你播放器、主要播放按钮与当前导航项使用同一材质。

实现依据：[Compose 图形图层](https://developer.android.com/develop/ui/compose/graphics/draw/modifiers)、[原生手势与事件消费](https://developer.android.com/develop/ui/compose/touch-input/pointer-input/understand-gestures)。这是一套实时背景采样与折角几何效果，不声称是光学光线追踪或真实纸张模拟。

# 0.5.0 系统媒体控制与悬浮导航

## 界面

媒体库分类按钮使用对称的水平与垂直内边距，使文字与 Material 点击反馈区域共用同一中心。文件夹长路径最多显示两行，完整来源仍保留在索引中。

底部导航使用两侧留白的半透明靛蓝悬浮面板、轻描边与中性选中底色。乐库列表可在面板下方滚动，末项保留足够底部空间；播放页内容避让面板，全屏时隐藏面板。系统手势条、三键导航栏、横向安全区分别保留。

图标按下时收缩，松手轻回弹；切换目标时略微抬起，选中底色短暂过渡。动效由 Compose 动画系统驱动，遵循系统动画时长设置，不使用持续循环。点击语义为标签选择，保留至少 48 dp 触控高度。

## 通知与锁屏

继续使用 Android 媒体会话与 MediaStyle 标准通知，不复制第三方播放器的私有通知布局。加载歌曲时先发布标题、艺术家、专辑、时长和默认封面，再发布第一条媒体通知；异步读取内嵌封面并替换。切歌取消上首封面读取，防止旧封面覆盖新歌。

系统媒体会话同步播放、暂停、缓冲、错误、进度及实际时长；提供上一首、播放／暂停、下一首和进度跳转。点击通知打开播放页，已有 Activity 直接处理请求；停止播放后清除媒体卡片与旧的会话信息。没有内嵌封面时使用已批准的栖声图标。

Android 13 起，系统可根据 PlaybackState 的动作生成媒体按钮；关联媒体会话的媒体通知属于通知运行时权限豁免范围。因此不为音乐播放额外强制弹出通用通知权限请求。厂商系统的通知卡片位置、背景、折叠方式、锁屏权限和第三方主题仍由系统控制。如果用户主动关闭了该应用的播放通知频道，需要在系统应用通知设置中重新打开。

参考：[Android 媒体控制](https://developer.android.com/media/implement/surfaces/mobile)、[通知运行时权限与媒体会话豁免](https://developer.android.com/develop/ui/compose/notifications/notification-permission)。

## 验证边界

设备测试检查分类文字与反馈区域的水平／垂直中心、导航与歌词回归，以及媒体通知会话令牌、歌曲信息、封面、三个动作按钮和通过系统 MediaController 发出的播放／暂停／切歌／进度控制。通知点击返回播放页也纳入测试。

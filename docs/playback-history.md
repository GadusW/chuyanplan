# 0.7.0 播放记录与恢复

从本版本开始保存最近播放与上次会话；0.6.0 没有落盘的旧播放记录无法追溯补齐。

- 打开应用后恢复上次歌曲、完整队列、播放位置、随机／循环选择，保持暂停；点播放后从保存位置继续。
- 乐库右上角的历史图标打开「最近播放」，保存最近 100 首不同歌曲。重复聆听会更新顺序，点某首可从其保存位置继续。
- 每 3 秒保存一次播放进度；暂停、拖动进度、改变随机／循环设置及服务结束时另存检查点。强行结束进程可能损失最后约 3 秒进度。
- 不将历史上传，也不复制或修改音频文件。音频移动、存储卡移除或读取授权撤销后，需要重新导入或授权。

历史和会话分别保存在 Room 的 listening_history、playback_resume 表中。单一应用级写入队列串行完成事务，避免服务销毁取消写入。队列只在发生变化时重新序列化，进度写入不重复解析整队列。恢复操作不会覆盖用户已开始的新播放请求。

数据库从 2 升到 3，迁移只增加两张表，不清空歌曲或离线分析缓存。测试覆盖 1→3 与 2→3 的数据保留、历史更新、关闭并重开数据库后的恢复，以及解码器从非零位置开始播放。

采用主流播放器常见的「恢复会话但不自动出声」方式。本版没有增加重启手机后系统自动唤起播放的广播或后台自启。

参考：[Android 播放恢复](https://developer.android.com/media/media3/session/background-playback#resumption)。当前解码链仍为 LibVLC，未迁移到 Media3。

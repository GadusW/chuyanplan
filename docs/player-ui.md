# 0.4.0 播放页与歌词

播放页围绕「让声音停泊」重新整理信息层级：上方轻量标题与全屏入口，中间封面／歌词，下方歌曲信息、细进度条、播放控制和半透明工具栏。使用靛蓝、暖月白、雾蓝色，保留栖声自己的月光唱片视觉。

设计参考 [Apple Music 的歌词开关与点句跳转方式](https://support.apple.com/en-us/109355)、[Apple Music 全屏播放器说明](https://support.apple.com/en-hk/guide/music-web/apdm5e4a7164/web)，以及 [网易云音乐官方商店页面](https://apps.apple.com/cn/app/id590338362) 中的封面与歌词呈现。参考的是层级、留白与操作关系，未复制界面素材或标识。

## 使用

- 点迷你播放器或「此刻」打开播放页。
- 右上角「全屏播放」图标隐藏系统栏及底部导航；同位置可退出。返回键先退出全屏，再次返回收起播放页。系统首次进入沉浸模式可能显示自己的操作提示；从屏幕边缘滑动可暂时唤出系统栏。
- 点封面或左下方歌词按钮切换歌词；开关选择会保留。单击歌词返回封面，也可点击歌词区域右上方「返回封面」。两种模式与横屏均支持返回；没有歌词时点击空白歌词区域也可返回。歌词开启后，工具栏提供导入按钮。无歌词时直接点「选择歌词文件」，为当前歌曲选择 LRC 或 TXT 文件。
- 已通过系统文件夹选择器授权的目录中，与音频同名的 `.lrc` / `.txt` 会尝试自动关联，优先 LRC。仅有音频权限无法读取任意文本文件，需授权该目录或手动导入歌词。
- LRC 逐行跟随播放，双击带时间戳的句子跳转；TalkBack 提供「跳转到这句歌词」自定义操作。单击用于返回封面。用户正在滚动时不强行打断，下一次歌词变化后恢复跟随。TXT 以静态文本呈现，不伪造时间信息。
- 支持常见多时间戳、毫秒时间和 `[offset:]`；支持 UTF-8、UTF-16 BOM，并对无法按 UTF-8 解码的文本尝试 GB18030。歌词最多 512 KB、最多处理 10,000 行。暂不支持联网歌词、音频内嵌歌词、翻译与逐字卡拉 OK。

## 视觉与兼容

模糊仅用于环境背景，不模糊歌词、按钮或文字。背景根据嵌入封面或默认品牌图案生成柔焦层，降低光晕强度；分析区改用细线分区，频谱保留一层轻量表面，工具栏取消重复的胶囊边框。封面缩小圆角，模式选择使用下划线，歌词正文提高非当前行可读性。乐库压缩品牌展示区，让歌曲更早出现在首屏。设计约定见 [DESIGN.md](../DESIGN.md)。歌词切换与高亮使用短淡入，原生交互遵循系统动效设置。

Compose 的均匀模糊需要 Android 12+；更旧系统保留柔和渐变和半透明层，不声称具备同样的实时模糊。[Android 官方依据](https://developer.android.com/develop/ui/compose/graphics/images/customize)

横屏采用视觉区与控制区双列；小屏减小留白和封面，横屏控制区可滚动。全屏内容避让显示缺口，退出页面时恢复系统栏。实际系统栏样式和刘海区域仍需不同机型验收。

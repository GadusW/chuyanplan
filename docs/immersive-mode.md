# 0.8.0 体感沉浸

在「此刻」播放页的「极简」「音频分析」旁选择「体感沉浸」，选择效果后进入。沿用靛蓝、月白、雾蓝色，不使用高亮闪烁或彩虹粒子。

## 三种效果

- **封面视差**：相对进入时的持握方向，封面产生有限的平移和轻微三维转动。
- **节奏波纹**：保留封面视差，当前播放波形的 RMS 与手部运动共同影响波纹亮度、强度和扩散速度。
- **节奏粒子**：保留封面视差，音频与手部运动驱动粒子、短拖尾与发光。固定容量为 176 粒子，不随音量无限增加；重音驱动向外喷散，倾斜与摇晃驱动流向和涡流。

0.7.0 中封面视差占屏比例增大，倾斜平移约 38／32 dp，叠加有衰减的摇晃冲量。新增线性加速度监听；缺失时用加速度减去低通重力估算，避免横向摇晃但角度变化很小就没有反馈。波纹中心偏移、扩散速度、线宽和粒子拖尾均对运动强度作出响应。

波纹与粒子从封面抽取主要彩色分量，以深色同色底、主色和次色呈现；忽略透明、近黑与近白区域。无封面或无法读取时使用栖声的蓝紫后备配色。文字和播放控制仍保持品牌配色。参考 [Material 3 Expressive 的色彩与运动方向](https://design.google/library/expressive-material-design-google-research) 和 [Android 运动传感器说明](https://developer.android.com/develop/sensors-and-location/sensors/sensors_motion)，不复制其他应用素材。

音频幅度和快慢包络的差值用于增强瞬态反馈，不根据歌曲名称推断摇滚，也不伪造节拍检测。节奏／振幅变化较强时效果更明显；它不是 BPM 分析或专业节拍跟踪器。静音、无信号和暂停时不伪造音频能量；手部运动仍可产生轻微反馈。

## 交互

进入后隐藏系统栏、底部导航、进度、上一首／下一首等控制，视觉区只保留封面／效果和简洁歌名。单击画面显示控制，可暂停、播放、切歌、调整进度或切换效果。10 秒没有触摸／拖动操作后自动隐藏控制，歌曲自身的进度更新不会重置计时。

连续轻点画面三下退出，相邻两次间隔需在 360 ms 内。控制层也提供明确的退出按钮，系统返回键先退出体感模式。TalkBack 有「显示播放控制」和「退出体感沉浸」自定义操作。横屏／小屏的控制层可滚动，不遮断退出路径。

## 真实音频输入与权限

PlaybackService 生成独立的正值 AudioSessionId，通过 LibVLC 的 `audiotrack-session-id` 传给 AudioTrack。Visualizer 仅连接这个会话，绝不退回全局 session 0，不监听其他应用。

请求最高 50 Hz 的当前播放波形回调，实际频率受设备 `getMaxCaptureRate()` 上限约束。优先以每个新波形块计算 `sqrt(mean(((sample-128)/128)^2))`，避免某些机型长窗口 RMS 测量将鼓点抹平；很轻的音乐被 8-bit 波形量化为零时，回落到 PCM 域 RMS 测量，将毫贝值转换为线性幅度。波形采用 AS_PLAYED 标度。这些数据适合视觉反馈，不用于替代无损 PCM 的 DR、响度或音质测量。不进行实时 FFT、不二次解码整曲，音频分析模式的缓存计算保持独立。

Android 的 Visualizer 接口要求 RECORD_AUDIO 运行时权限，系统可能将它显示为「录音／麦克风」。选择波纹或粒子前说明用途，首次启用才请求；不使用 AudioRecord、MediaRecorder 或麦克风输入，也不写入音频文件。封面视差无需此权限。拒绝授权、波形接口不可用或会话未就绪时保留运动效果，控制层提供实际状态与重试授权入口，不使用虚构 RMS。

参考：[Visualizer API](https://developer.android.com/reference/android/media/audiofx/Visualizer)、[VideoLAN 的会话 ID 支持](https://mailman.videolan.org/pipermail/vlc-commits/2018-February/047694.html)。

## 滤波与资源

优先选择游戏旋转矢量／旋转矢量（通常融合陀螺仪），避免仅积分角速度的长期漂移；缺失时降级到重力／加速度倾斜，没有传感器时封面保持静止。映射屏幕旋转方向，先将旋转矩阵变换到进入时的持握基准，再提取相对角度，避免手机接近直立时世界坐标欧拉角翻转；对环绕角、平移幅度和运动强度限幅。

0.8.0 的倾斜滤波会随移动速度调整：静止时约 65 ms，明显移动时最快约 18 ms；摇晃方向低通为 45 ms。绘制端使用 32 ms 插值，将 50 Hz 传感器输入连到显示帧，封面、水波与粒子共用同一个平滑姿态。主动动画不再附加 24 ms 延迟，随屏幕帧时钟调度；这不等于保证所有设备都能维持其最高刷新率。

音频的视觉能量使用缓慢衰减的峰值作为自适应参考，不再把持续较响的音乐压成一直满幅。对当前块的 RMS 上升量和局部平均的差异共同检测瞬态，设置约 160 ms 触发间隔；稳定长音不会不断触发大爆发。重音以单调事件编号跨回调传递，画面只消费一次，避免在较慢显示设备重复触发。无新输入超过 350 ms、暂停或权限不可用时，音频能量衰减到零。

### 水波与粒子的运动

- 水波：每个重音推出一组水波，新生阶段带次波峰；最多保留 8 组，绘制最近 5 组以限制过度绘制。轮廓用平滑二次曲线，不重复叠加宽描边发光。绘制间隔持续偏大时自动从 48 点／5 组降到 24 点／2 组，粒子减少显示密度并关闭外晕；响应恢复稳定后再提高细节，保持主要重音冲量和随动。多组低频正弦轮廓形成连续起伏，波峰传播、干涉感和衰减随真实时间更新。手机倾斜改变轮廓的流向和拉伸，摇晃移动波源并扰动波峰；持续音乐只留下较轻的表面流动。
- 粒子：重音一次喷散 24–56 个，粒子池固定为 176。初速度、寿命和大小有有限变化，速度方向决定短拖尾，随后阻尼减速并消散。倾斜产生横向／纵向水流，摇晃注入定向冲量与涡流；细微飞沫负责连接重音之间的空隙。
- 两种效果保留封面取色和清楚的文字；强拍增强局部波峰与喷散，不用全屏白闪。没有音频时，手部运动仍可产生扰动，但不会显示虚构的音乐拍点。

传感器、Visualizer 和绘制协程均随可见界面生命周期停止，退出后注销／释放。封面视差不监听音频，但使用帧时钟平滑运动；暂停静止且余波消退后降低刷新。系统「移除动画」开启时呈现静态封面，停用传感器与实时音频监听。效果强度、真实刷新率和长期耗电仍需手机验收。

实现参考：[Android Visualizer](https://developer.android.com/reference/android/media/audiofx/Visualizer) 的波形采集与频率上限，以及 [Compose 绘制阶段优化](https://developer.android.com/develop/ui/compose/performance/phases)。传感器／音频状态在帧循环和控制层内按需读取，连续动画状态在 Canvas／graphicsLayer 中读取，避免为每个显示帧重新布局。波纹／粒子页不再绘制被完全遮挡的全屏模糊背景，封面缩到约 52% 屏宽，为效果留出空间，局部高光混入月白以保持深色专辑上的辨识度；不用逐帧全屏渐变填充换取刺激感。

## 0.7.0 切换与退出稳定性

波纹和粒子之间切换复用同一播放波形监听，不重复创建效果器。取消时先关闭回调入口，移除监听、禁用效果，再释放原生资源；迟到的回调不会再测量已经释放的对象，设备的状态异常也不会直接抛到界面线程。测试包含 24 次真实效果器建立／释放，以及 24 次界面效果切换后退出。

# 0.7.0 体感沉浸

在「此刻」播放页的「极简」「音频分析」旁选择「体感沉浸」，选择效果后进入。沿用靛蓝、月白、雾蓝色，不使用高亮闪烁或彩虹粒子。

## 三种效果

- **封面视差**：相对进入时的持握方向，封面产生有限的平移和轻微三维转动。
- **节奏波纹**：保留封面视差，当前播放波形的 RMS 与手部运动共同影响波纹亮度、强度和扩散速度。
- **节奏粒子**：保留封面视差，音频与手部运动驱动粒子、短拖尾与发光。粒子数固定为 108，不随音量无限增加。

0.7.0 中封面视差占屏比例增大，倾斜平移约 38／32 dp，叠加有衰减的摇晃冲量。新增线性加速度监听；缺失时用加速度减去低通重力估算，避免横向摇晃但角度变化很小就没有反馈。波纹中心偏移、扩散速度、线宽和粒子拖尾均对运动强度作出响应。

波纹与粒子从封面抽取主要彩色分量，以深色同色底、主色和次色呈现；忽略透明、近黑与近白区域。无封面或无法读取时使用栖声的蓝紫后备配色。文字和播放控制仍保持品牌配色。参考 [Material 3 Expressive 的色彩与运动方向](https://design.google/library/expressive-material-design-google-research) 和 [Android 运动传感器说明](https://developer.android.com/develop/sensors-and-location/sensors/sensors_motion)，不复制其他应用素材。

音频幅度和快慢包络的差值用于增强瞬态反馈，不根据歌曲名称推断摇滚，也不伪造节拍检测。节奏／振幅变化较强时效果更明显；它不是 BPM 分析或专业节拍跟踪器。静音、无信号和暂停时不伪造音频能量；手部运动仍可产生轻微反馈。

## 交互

进入后隐藏系统栏、底部导航、进度、上一首／下一首等控制，视觉区只保留封面／效果和简洁歌名。单击画面显示控制，可暂停、播放、切歌、调整进度或切换效果。10 秒没有触摸／拖动操作后自动隐藏控制，歌曲自身的进度更新不会重置计时。

连续轻点画面三下退出，相邻两次间隔需在 360 ms 内。控制层也提供明确的退出按钮，系统返回键先退出体感模式。TalkBack 有「显示播放控制」和「退出体感沉浸」自定义操作。横屏／小屏的控制层可滚动，不遮断退出路径。

## 真实音频输入与权限

PlaybackService 生成独立的正值 AudioSessionId，通过 LibVLC 的 `audiotrack-session-id` 传给 AudioTrack。Visualizer 仅连接这个会话，绝不退回全局 session 0，不监听其他应用。

系统以约 20 Hz 提供当前播放的波形回调。优先读取 Visualizer 的 PCM 域 RMS 测量，将毫贝值转换为线性幅度，避免很轻的音乐被 8-bit 波形量化为静音；不支持测量时，每块以 `sqrt(mean(((sample-128)/128)^2))` 计算波形 RMS。波形采用 AS_PLAYED 标度。这些数据适合视觉反馈，不用于替代无损 PCM 的 DR、响度或音质测量。不进行实时 FFT、不二次解码整曲，音频分析模式的缓存计算保持独立。

Android 的 Visualizer 接口要求 RECORD_AUDIO 运行时权限，系统可能将它显示为「录音／麦克风」。选择波纹或粒子前说明用途，首次启用才请求；不使用 AudioRecord、MediaRecorder 或麦克风输入，也不写入音频文件。封面视差无需此权限。拒绝授权、波形接口不可用或会话未就绪时保留运动效果，控制层提供实际状态与重试授权入口，不使用虚构 RMS。

参考：[Visualizer API](https://developer.android.com/reference/android/media/audiofx/Visualizer)、[VideoLAN 的会话 ID 支持](https://mailman.videolan.org/pipermail/vlc-commits/2018-February/047694.html)。

## 滤波与资源

优先选择游戏旋转矢量／旋转矢量（通常融合陀螺仪），避免仅积分角速度的长期漂移；缺失时降级到重力／加速度倾斜，没有传感器时封面保持静止。映射屏幕旋转方向，相对初始姿态校准，并对环绕角、平移幅度和运动强度限幅。

倾斜低通时间常数 120 ms，运动强度 80 ms，摇晃强度约 100 ms；音频先以约 −80 至 −15 dB 的对数区间映射视觉强度，再使用 70 ms 快包络和 280 ms 慢包络，让低音量时的效果仍可辨识，静音仍为零。系数由实际时间间隔计算，降低采样率变化导致的手感差异。传感器约 50 Hz，通道只保留最新数据，画面以约 30 fps 的上限绘制；暂停静止时降低更新频率。

传感器、Visualizer 和绘制协程均随可见界面的生命周期停止，退出后注销／释放；封面视差不启动音频波形监听或帧动画。遵循系统「移除动画」设置，改为静态呈现。效果强度和机型耗电仍需真实手机长期验收。

## 0.7.0 切换与退出稳定性

波纹和粒子之间切换复用同一播放波形监听，不重复创建效果器。取消时先关闭回调入口，移除监听、禁用效果，再释放原生资源；迟到的回调不会再测量已经释放的对象，设备的状态异常也不会直接抛到界面线程。测试包含 24 次真实效果器建立／释放，以及 24 次界面效果切换后退出。

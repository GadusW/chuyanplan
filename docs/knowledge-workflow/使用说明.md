# 栖声知识工作流使用说明

这套工具供开发者在电脑上使用。它把导入资料、让 agent 写作、预览审核和知识包签名连接起来。换一个 agent 时，仍然可以沿用已有资料和草稿。

## 先了解当前范围

现在可以导入 PDF、文字或图片，生成交接任务，制作草稿，检查格式，审核并生成签名知识包。电脑工作台只在本机打开。

Android 0.13.0 已接入签名知识包导入，内置 6 篇三分钟样稿。后续可以逐步扩展到 24 篇。休息提醒和知识书架都使用新的知识阅读界面。

使用现有 agent 制作内容，消耗该 agent 自身的会话额度。本工具没有另外购买云端 AI 服务。也支持你选择电脑上已有的本地模型，速度和质量取决于硬件。

## 第一次使用

1. 用文件资源管理器打开项目文件夹，例如 D:\chuyanplan。
2. 进入 tools，再进入 knowledge。
3. 双击“启动知识工作台.cmd”。
4. 浏览器会打开本机工作台。保留启动时出现的终端窗口，关掉终端就会停止工作台。浏览器地址每次启动可能不同。

如果提示缺少 Python，把下面这段话交给你正在使用的 agent。

> 请按本项目 docs/knowledge-workflow/使用说明.md 准备知识工作台。检查 Python 3.10 或更高版本，并用同一个解释器安装 tools/knowledge/requirements.txt 中的签名依赖。完成后启动本地工作台，原有签名密钥要保留。

工具优先复用 Codex 自带的 Python，也会查找电脑上已有的 Python。首次需要 cryptography 签名依赖时，agent 可在项目虚拟环境中安装。网络不通时应报告依赖未安装，已经可用的导入和草稿检查仍可继续。

## 每次投送新知识

### 第一步，导入资料

在“参考资料”下点击文件选择框，直接选择 PDF、文字或图片。每个文件最多 80 MB。也可以展开“使用本机文件路径导入”，粘贴“复制文件地址”的结果，两端的英文引号可以保留。

导入成功后，点击资料下的“整理资料”。这里可以打开原件、填写知识笔记、查看给 agent 的任务，或直接新建草稿。

TXT 和带文字层的 PDF 可以点击“提取文字”。PDF 每次选 1–10 页。两本扫描教材没有可提取的文字层，工作台会明确提示；可以打开原件，把任务交给能识图的 agent，核对后保存笔记。

工作台在本机复制一份原件并生成来源编号，同一个文件重复导入会沿用已有编号。

### 第二步，把任务交给任意 agent

选择资料后点击“给 agent 的任务”，在弹出的窗口里点击“复制任务”，再粘贴到你使用的 AI 编程助手中。剪贴板被浏览器禁止时，可以选中窗口里的任务文字，按 Ctrl+C。需要时补上“先做 2 篇让我看看”。

如果这个 agent 没有自动读取项目规则，可以直接发下面的通用提示。

> 请打开这个项目，读取 AGENTS.md、skills/stillune-knowledge/SKILL.md 和 docs/knowledge-workflow/使用说明.md。运行 status 查看现有来源，继续我指定的资料任务。使用你当前的阅读写作能力生成独立三分钟草稿，逐篇核对原页，保存后告诉我去工作台审核。先做 2 篇。

agent 需要能读取本机项目和原始文件。网页聊天工具若无法访问这些文件，需要你提供相应资料和工作流文件，生成 JSON 后再由本机 agent 导入。

### 第三步，自己阅读并审核

回到工作台点击“刷新进度”，在草稿下选择“编辑”。也可以直接导入 agent 生成的 JSON 文件，或者在资料页点击“新建草稿”。

标题、正文、收尾、标签和参考页码都有普通输入框，无需编辑 JSON。正文每段之间空一行，PDF 页码用逗号分隔。确认参考原页后，勾选对应的“已对照原页核验”。

点击“预览阅读”查看文章，点击“保存修改”检查字数和引用。错误会显示在参考出处下方。刷新列表会保留未保存的正文和笔记，离开当前草稿时会提醒。若其他 agent 同时改过这篇，工作台会阻止旧页面覆盖新版本，需要先刷新重新选择，再合并你的修改。

满意后，填写审核人和审核记录，勾选“我已读完当前版本”，点击“通过审核”。正文未保存、引用未核验、格式不通过时，按钮会保持不可用，并显示检查结果。改稿会使旧审核失效。

审核记录可以写“已核对书籍 PDF 第 54 页，正文和例子可读，同意发布”。可以用搜索和筛选寻找草稿。暂时撤下的文章可点“归档这篇”，之后从“已归档草稿”恢复。

### 第四步，生成知识包

首次建立签名密钥只需操作一次。本机已经为 Android 0.13.0 建立发布密钥，按钮显示不可点击时表示已有密钥，后续沿用即可。如果其他电脑提示依赖缺失，请 agent 完成上面的首次准备。

请立即把 .knowledge-workspace\keys 文件夹备份到你自己保管的离线位置。换电脑时继续使用同一份密钥。private.pem 是私钥，只放在你的电脑和备份中；public.pem 是用于验证内容的公钥，之后会接入安卓应用。

版本号会自动建议为下一版。点击“生成签名知识包”后，在知识包列表点击“下载知识包”，即可用浏览器保存 ZIP。项目的 output\knowledge 文件夹也保留原文件。

包里只收录审核仍有效的文章。每个包是完整内容快照，导入会替换上一份知识目录，准备发布时请确认希望保留的文章也在包中。要撤回某篇，可以让 agent 将该草稿移到归档目录，再生成一个更高版本的完整知识包。

## 换 agent 怎么接着做

在同一个电脑、同一个项目文件夹里，把下面这段话交给下一位 agent。

> 继续栖声知识制作。先读 AGENTS.md 指向的技能和说明，运行 tools/knowledge/workflow.py status，告诉我有哪些来源、待核验草稿和已审核文章。继续我指定的任务，保留已有资料与密钥。

换电脑时，需要转移项目，以及私下转移 .knowledge-workspace。GitHub 里默认没有你的教材、草稿、审核记录或私钥。只克隆仓库会得到工具和规则。

## 想让本地模型自动写草稿

这是可选方式。可以继续让当前 agent 完成转化，也可以请 agent 检查电脑配置、安装 Ollama 并选择适合的本地模型。安装模型需要一次网络下载和磁盘空间。

在资料页把已核对的简短知识点放入“笔记与待转化内容”，点击“保存笔记”。之后点击“检测本地模型”，选择电脑上已安装的模型，再点“生成三分钟草稿”。

生成在后台运行，页面会显示状态，可以继续查看其他资料。完成后会出现待核验草稿。请保持启动工作台的终端窗口运行，关闭它会停止未完成的生成任务。

如果提示“未连接本机 Ollama”，可以继续把任务交给当前 agent。工作台不会自动替你下载大模型。需要本地模型时，请 agent 先检查配置和磁盘空间再安装。

agent 也可以继续使用命令行。

```powershell
python tools/knowledge/workflow.py local-draft SOURCE_ID --model MODEL
```

工具调用本机模型。生成不会自动通过审核，也不会直接发布给用户。

## 如何更新到用户手机

把生成的 ZIP 文件发送到手机，保存到本机文件夹。在栖声里打开「护耳 → 打开知识书架」，滑到下方点「导入知识更新」，从系统文件选择器里找到这个 ZIP。通过校验后会显示内容包版本和篇数，之后可以离线阅读。

应用已固定本机工作区生成的发布公钥。保留 .knowledge-workspace/keys 中的原私钥，后续继续用它签名。用另一台电脑创建新密钥，旧版手机应用会拒绝对应知识包。换发布密钥需要通过新的应用版本更新可信公钥。

首批 6 篇对应的草稿也在本机工作台，可继续审阅、修改。APK 内置样稿来自开发实现，工作台里的草稿仍等待你的逐篇审核。

之后若希望用户自动收到新文章，需要一个可访问的静态下载地址。可以评估免费额度的国内静态托管，记录容量和流量限制。确认托管方式后，agent 再配置发布流程。当前工具没有创建公网服务或自动上传教材。

日常所谓“自动推送”建议实现为应用检查新版本并下载到本地。文章只在用户休息阅读时出现。即时系统通知与内容更新是两个独立功能，后续按你的选择接入。

## 给 agent 的命令参考

请在项目根目录打开终端。python 指同一个 Python 解释器。

```powershell
python tools/knowledge/workflow.py status
python tools/knowledge/workflow.py ingest "D:\资料\一本书.pdf" --title "资料名称"
python tools/knowledge/workflow.py template SOURCE_ID --id one-clear-question
python tools/knowledge/workflow.py save "D:\草稿\one-clear-question.json"
python tools/knowledge/workflow.py check
python tools/knowledge/workflow.py approve one-clear-question --reviewer "开发者" --note "具体批准依据"
python tools/knowledge/workflow.py keygen
python tools/knowledge/workflow.py package --version 1
python tools/knowledge/workflow.py verify "output\knowledge\stillune-knowledge-1.zip" --public-key ".knowledge-workspace\keys\public.pem"
```

template 命令把字段骨架输出到终端。agent 可用 UTF-8 保存成 JSON 后填写。自动校验通过只说明字段、字数和引用记录符合要求，仍需阅读内容。

## 常见情况

| 提示或现象 | 处理方法 |
| --- | --- |
| 导入后没有文章 | 在资料页新建草稿，或把任务交给 agent；也可保存笔记后使用已安装的本地模型 |
| 原件已变动 | 重新导入变动后的文件，由 agent 重新核验并更新引用 |
| 审核失效 | 草稿或来源记录改变了，读完新版本后重新审核 |
| 生成知识包按钮不可用 | 检查签名提示，处理格式错误、核验引用，再审核至少一篇 |
| 版本号已用过 | 改成更大的整数，保留已发包 |
| 找不到旧资料 | 确认打开的是原来的项目文件夹，或恢复私有工作区备份 |
| 工作台按钮点击后无反应 | 确认启动窗口还在运行，刷新浏览器到新版页面，并查看顶部错误提示 |
| 手机暂时没有变化 | 把 ZIP 发到手机，打开知识书架导入；生成包本身只发生在电脑上 |

## 工作台验证

agent 可以运行核心测试。浏览器测试需要临时安装 playwright，使用电脑上的 Microsoft Edge，所有测试审核与知识包都在隔离目录中产生。

```powershell
python tools/knowledge/test_workflow.py
python tools/knowledge/test_workbench_browser.py
```

浏览器测试覆盖文件上传、原件和任务查看、笔记提取、表单编辑、刷新保护、审核、签名下载、其他 agent 改稿冲突、归档恢复和 JSON 导入。本地模型队列使用模拟服务验证，实际生成能力还需电脑上有可用模型。

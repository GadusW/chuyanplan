发布知识包

包含全部审核仍有效的文章。发到手机后，在栖声知识书架选择“导入知识更新”。

下载后，怎样在手机里使用？
  1. 把 ZIP 发送到手机，保存到“下载”文件夹，保留 ZIP 原样。
  2. 打开栖声 → 护耳 → 打开知识书架 → 右上角“导入知识更新”。
  3. 选择这个 ZIP，看到更新成功和篇数后，即可离线阅读。

生成和下载发生在电脑上；工作台无法确认手机是否已成功导入。每个包是完整目录，会替换手机上的上一版知识内容。

交给 agent 的任务

阅读预览

第一次，先读一篇现有草稿

不用先导入教材，也不用配置模型。点击“打开一篇草稿”，然后“预览阅读”，就能看到用户将读到的内容。

  1. 想改内容：直接编辑标题、正文，点“保存修改”。
  2. 确认内容与出处：对照原页核验，填审核人和记录，再点“通过审核”。
  3. 想放到手机：生成知识包 → 下载 ZIP → 手机知识书架导入。

以后补充资料：导入文件 → 整理资料 → 给 agent 的任务。agent 就是你现在使用的 AI 助手；复制任务发给它即可。没有草稿时从导入资料开始。
